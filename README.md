# Synaps Clone (beta.synaps.app)

An original-code reimplementation of the Synaps product UI
(beta.synaps.app), built from REA-assisted public-surface analysis.

**This is an educational clone. It is not affiliated with, endorsed by, or
connected to Synaps. All product names, trademarks and copy belong to their
respective owners.** No Synaps source code is used — every file here is
written from scratch from publicly observable UI structure.

## Contents

- `ANALYSIS.md` — the honest reverse-engineering analysis (public surface
  only; everything behind the login is explicitly marked as unobserved)
- The clone application itself (see the analysis for the route map)

## Status

Work in progress — milestones are landed one at a time, each gate-verified
(commits must exist on disk before any milestone is declared complete).
