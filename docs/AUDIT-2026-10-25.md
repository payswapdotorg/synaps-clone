# Audit report — synaps-clone vs synaps.app

**Date:** 25 October 2026 · **Auditor:** Z.ai Code (TL) · **Task ID:** 55
**Scope:** machine-facing surfaces (URL shape, robots, sitemap, head metadata, JSON-LD), the blog imagery layer, structured-data shapes, and content drift — the surfaces not yet covered by the viewport-spectrum / preference-media / security-header / dialog-a11y passes of Tasks 46–54.
**Method:** live harvest via HTTP (79 sitemap URLs, per-page-type probes, per-post H1/title fitting, per-role JSON-LD), diffed against the clone's source and deployed output.

---

## Findings

### F1 — Trailing-slash policy is inverted [HIGH · behavioral]
Live runs `trailingSlash: true`: `/pricing` → **308 → `/pricing/`**, and every canonical, og:url, sitemap URL, and JSON-LD URL carries a trailing slash (79/79 sitemap URLs). The clone runs the Next.js default (false) — the exact **opposite redirect direction** (`/pricing/` → 308 → `/pricing`), and emits slash-less canonicals.
**Fix:** `trailingSlash: true` in `next.config.ts`; emit slash URLs from the single `pageMeta` choke point, the sitemap builder, and the JSON-LD URL builders. Internal `<Link>` hrefs are normalized by Next automatically.

### F2 — The blog imagery layer is absent [HIGH · visual + machine]
Live: **every one of the 31 posts carries a unique CMS image** (1200×630) used in four places — blog-hub card grid, post-page hero, `og:image`, and `BlogPosting.image`. The hub is a `ds-card-grid` of image cards (`ds-blog-card`: image → category · date/read → title → excerpt, featured variant for the newest).
Clone: hub = one standing-in studio photo on the featured card + text-only rows for the rest; post pages have no hero; `og:image` is the site default for every post.
**Fix:** generate **31 original black-and-white editorial cover images** (own-asset doctrine, same provenance as the existing studio-table.png), add `image` + `category` fields to `blog.ts`, and wire them into the hub card grid, the post hero band, `og:image`, and `BlogPosting.image`.

### F3 — Per-post category data missing [MED · data]
Live card labels and `articleSection` values: **Studio workflows ×25, Practice ×3, Essay ×3** (full per-post mapping harvested). The clone has no category field; the featured card hardcodes "Studio workflows".
**Fix:** `category` field on `BlogPostData`; hub card labels; `articleSection` in `BlogPosting` JSON-LD.

### F4 — Sitemap lacks priorities and real lastmods [MED · machine]
Live sitemap: `<priority>` on all 79 URLs (home 1.0 · pricing 0.9 · company/solutions/careers 0.8 · legal/faq/partners 0.7 · news 0.6) and **real per-page lastmods** (e.g. home 2026-09-30, pricing 2026-10-08, imprint 2026-07-03). Blog lastmod = **latest publication date** (all 31 = 2026-10-23 — a CMS rule, not per-post dates); changelog entries uniformly 2026-10-08.
Clone: no priorities at all; statics share a single `CONTENT_DATE` anchor.
**Fix:** transcribe the priority classes and the per-page lastmod table; compute blog lastmod as the newest post date; changelog fixed at the harvested 2026-10-08. Docs entries (the clone's own same-domain addition, no live counterpart) keep a sub-news priority.

### F5 — robots.txt disallow list is 2 lines short [MED · machine]
Live:
```
Disallow: /company/team-variants/
Disallow: /company/careers/careers-grid-
Disallow: /dev/
Disallow: /preview/
```
Clone ships only the last two. The robots.txt is a public file — the full list is the transcription-parity target (Disallow entries for non-existent routes are inert).
**Fix:** transcribe all four lines verbatim.

### F6 — Structured-data shape drift [MED · machine]
- `BlogPosting.author` on live is an **inline** `{@type: Organization, name}` — the clone emits an `@id` ref. (Publisher stays an `@id` ref — matches live.)
- Live post page carries **exactly one** JSON-LD block (`BlogPosting`); the clone also mounts `organizationLd` there. Same for changelog entries (live: `Article` only).
- `JobPosting` on live: `datePosted: 2026-07-06` (all five roles), `employmentType` **PART_TIME for architectural-designer** / FULL_TIME for the rest, and **no** `applicantLocationRequirements` key. The clone lacks `datePosted`, derives employmentType from "Working student", and emits `applicantLocationRequirements` from `location`.
**Fix:** inline author, single-block mounts, `datePosted` constant, per-role employmentType transcribed, drop `applicantLocationRequirements`.

### F7 — Company page mounts the wrong Organization variant [MED · machine]
Live `/company/` carries a **rich** Organization block: `legalName: "synaps GmbH"`, `foundingDate: "2023"`, `address: {PostalAddress, Vienna, AT}`, `email: "office@synaps.app"`, `sameAs: [linkedin, instagram]` — distinct from the home page's thin variant (which the clone already mirrors). The clone's company page reuses the home variant.
**Fix:** transcribe the rich variant (harvested facts kept verbatim, `name` identity-adjusted to "Synaps Clone" per doctrine).

### F8 — `<title>` truncation rule missing [MED · machine]
Live truncates the **final** title string (post title + " | Synaps") at the last word boundary within 69 chars, appending `…`; 14 of 31 posts are affected, and `og:title` truncates **identically**. Verified by fitting the rule against all 14 truncated + all non-truncated samples (`max non-truncated = 69`).
**Fix:** `wordcut` helper in the blog `[slug]` metadata — apply to the live-suffix string, emit truncated results as `absolute` titles.

### F9 — og:image sub-tag extras [LOW · machine]
Live emits a single bare `<meta property="og:image">`; the clone additionally emits `og:image:width/height/alt`.
**Fix:** configure images as bare strings.

### F10 — `article:published_time` extra [LOW · machine]
The clone emits it (via `openGraph.publishedTime`); live does not.
**Fix:** drop the field.

### F11 — `viewport-fit=cover` missing [LOW · machine]
Live viewport: `width=device-width, initial-scale=1, viewport-fit=cover`. The clone's `Viewport` export sets only `themeColor`.
**Fix:** add `viewportFit: "cover"`.

### F12 — apple-touch-icon quirk not transcribed [LOW · quirk]
Live's apple-touch-icon points at the **SVG favicon** (not a PNG). The clone ships a 180×180 PNG.
**Fix:** transcribe the quirk — apple-touch → the clone's `favicon.svg`.

### F13 — Pricing title punctuation [LOW · content]
Live: `Synaps pricing, Freemium, Pro & Studio plans` (comma). Clone uses an em dash.
**Fix:** comma.

### F14 — Career breadcrumb anchor [LOW · route]
Live breadcrumb item 3: name "Careers", item `/company/#company-careers` (the company page carries `id="company-careers"` + `id="company-careers-title"`). The clone uses `/company#careers` and its company page has `id="careers"`.
**Fix:** rename the anchors, update the breadcrumb item.

### F15 — Orphaned / retired assets [LOW · asset]
`public/images/blog/rolled-drawings.png` has zero references. `studio-table.png` becomes redundant once the featured card uses the post's own cover (F2).
**Fix:** retire both.

### F16 — Date display format [LOW · visual, found during implementation]
Live renders dates inside `<time>` as long form ("23 October 2026", machine value ISO); the clone displayed raw ISO strings ("2026-10-23") on the blog hub cards, post hero and changelog entries.
**Fix:** shared `formatDisplayDate` (en-GB long, UTC) used at all three display sites.

### F17 — Reference-site quirks, documented, no action [INFO]
- **Live home JSON-LD offers are stale**: Freemium 0 / Pro €35 / Studio €75 vs the live pricing page's €59 / €119 (€49/€99 annual). The clone is self-consistent with the current displayed prices (0/59/119) — kept.
- **`/company/careers/` on live serves a 200 empty stub** (no title, no h1, no main, 406-byte body). Nothing to transcribe; the clone 404s.
- **Live 404 is an empty shell** (no `<title>`, empty body). The clone keeps its informative 404 — documented deviation.
- Blog hub carries no JSON-LD on live — the clone matches. ✓
- Non-post pages all use the site-default og image on live — the clone matches (own asset). ✓
- Identity layer (titles/descriptions/site name/sameAs=[github]/Organization name) intentionally clone-identified per the honest-clone doctrine — unchanged.
- **Content drift: none.** Blog 31/31 (incl. the two 22–23 Oct posts from `bd271bf`), changelog 14/14 (latest 2026-10-07 both sides), pricing current, careers 5/5, solutions 10/10, alternatives 6/6, per-page title patterns otherwise shape-matched.

## Implementation plan (this report's suggestions)

1. `next.config.ts` — `trailingSlash: true` (F1)
2. `src/lib/seo.ts` — slash-normalizing `pageMeta`; `wordcut` title helper; JSON-LD builders: inline-author `blogPostingLd` (+ `articleSection`, per-post image), `jobPostingLd` (+ `datePosted`, per-role type, minus location requirements), rich `companyOrganizationLd`, slash URLs in `siteNavLd`/`breadcrumbLd`/`aboutPageLd` (F1, F3, F6, F7, F8)
3. `src/app/robots.ts` — full four-line disallow list (F5)
4. `src/app/sitemap.xml/route.ts` — a route handler replacing the metadata-convention `sitemap.ts`, because Next's serializer cannot express the live file's shape: date-only lastmods (it forces full ISO), decimal `1.0` priorities (it emits `1`) and the lexicographic URL order. The emitted file is byte-identical to live modulo the domain and the documented /docs addition (F4)
5. `src/app/layout.tsx` — `viewportFit`, bare-string og images, apple-touch → favicon.svg (F9, F11, F12)
6. `src/content/blog.ts` + `types.ts` — `category` and `image` fields on all 31 posts (F2, F3)
7. Blog hub page — image-card grid (featured + 30), category labels (F2, F3)
8. Blog `[slug]` page + `BlogPostView` — hero band, per-post `og:image`, `articleSection`, truncation rule, single-block JSON-LD, drop `publishedTime` (F2, F6, F8, F10)
9. Changelog `[date]` page — single-block JSON-LD (F6)
10. Company page — rich Organization mount, `#company-careers` anchors (F7, F14)
11. Careers `[slug]` page — breadcrumb item, `datePosted`, employment types (F6, F14)
12. Pricing page — title comma (F13)
13. Generate 31 covers → `public/images/blog/covers/{slug}.png` (1344×768, B&W editorial) (F2)
14. Retire `rolled-drawings.png` / `studio-table.png` (F15) — plus the now-unreferenced `apple-touch-icon.png` (F12)
15. Long-form date display at the three sites (F17)
16. Gates: cold build · `check:quality` · local prod `:3107` E2E (incl. `/go/x` redirect under trailing-slash) · deploy · production verification

**Verification targets:** 308 direction matches live on sample routes; sitemap diff = empty modulo the domain + docs addition; robots diff = empty modulo sitemap line; `<title>`/`og:title` byte-equal to live's shapes on all 31 posts (identity-adjusted suffix); JSON-LD block sets per page type match live; hub renders 31 image cards; zero console errors; viewport spectrum re-check on the new hub grid.

## Verification notes (post-deploy, a3cffac)

Production verification: **13/15 checks green on first pass; both failures were probe artifacts**, re-verified clean:

- **Sitemap**: the first fetch raced the deploy and compared against a stale edge copy; a fresh fetch is byte-identical to the live file modulo the domain and the /docs addition (0 diff lines).
- **Long date**: renders correctly ("23 October 2026"); the probe searched for live's lowercase `datetime` attribute while React 19 SSR emits camelCase `dateTime`. HTML attribute names are ASCII case-insensitive — the parsed DOM is identical. Recorded as a platform artifact alongside robots' `text/plain` (vs live's `text/plain; charset=utf-8`) content-type.

Also noted: under `trailingSlash: true` the `/go/{handle}` creator links gain one 308 normalization hop before the 302 (live serves the 302 directly from the edge). Final URL, UTMs and attribution are identical.

**Green checks**: redirect direction 308 → slash · sitemap byte-parity · robots verbatim · truncated title/og:title byte-identical · JSON-LD sets per page type (BlogPosting / BreadcrumbList+Organization+AboutPage / BreadcrumbList+JobPosting) · covers 200 · security headers intact · viewport-fit=cover · apple-touch SVG · canonical/og:url slashed · bare og:image + no published_time · per-post og:image.
